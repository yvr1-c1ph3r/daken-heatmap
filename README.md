# daken-heatmap

beatmania IIDXのプレーデータ（CSV）から、打鍵数のヒートマップを表示するツールです。

**▶ ツールを開く：https://yvr1-c1ph3r.github.io/daken-heatmap/**

## できること

- CSVを読み込み、日付ごとの打鍵数をGitHub風のヒートマップで表示
- **ブックマークレットで公式サイトから自動連携**（v2.0.0〜）
- 稼働バージョン単位（VER）または月単位（MONTH）で表示を切り替え
- 合計打鍵数・プレー日数・対象期間を自動集計
- カラーテーマを9色から選択可能（設定はブラウザに保存）
- スマホ・PC両方の画面幅に対応

## 使い方

### ブックマークレットで自動連携（おすすめ）

**最初に1回だけ：ブックマークレットを登録する**

1. 上の「ツールを開く」のページを開く
2. 入力画面下部の「KEYS HEATMAP連携」ボタンを、ブックマークバーにドラッグ＆ドロップする
   - スマホの場合：「コードをコピー」を押す → 適当なページをブックマークに追加 → そのブックマークを編集し、URL欄をコピーした内容に書き換える

**毎回の使い方**

1. e-amusement GATEにログインし、[CSVダウンロード画面](https://p.eagate.573.jp/game/2dx/34/djdata/score_download.html)を開く
2. 登録したブックマークを押す
3. 新しいタブでヒートマップが表示される

> 仕組み：ブックマークレットがCSVダウンロード画面の「IIDXタワーCSV」（プレー日,鍵盤,スクラッチ）を取得し、URLの `#csv=` に載せてこのツールを開きます。`#` 以降はサーバーに送信されず、読み込み後はURLから消去されます。データはお使いのブラウザ内にのみ保存されます。

### 手動で読み込む

1. [CSVダウンロード画面](https://p.eagate.573.jp/game/2dx/34/djdata/score_download.html)の「IIDXタワーCSVダウンロード」でCSVをダウンロード、もしくは表示された内容をコピーする
2. ツールの画面でCSVファイルをドラッグ＆ドロップ、または内容をテキストエリアに貼り付けて「ヒートマップを表示」を押す

CSVの形式は「プレー日,鍵盤,スクラッチ」（例：`2026/07/05,60568,3427`）です。

### うまくいかないとき

- 前回のデータが保存されていると、開いた直後にヒートマップが表示されます。入力画面に戻るには「← CSVを読み込み直す」を押してください
- ブックマークレットでエラーが出る場合は、e-amusement GATEにログインしているか確認してください

## 自分でホストする場合

`index.html`・`manifest.webmanifest`・`icon/` を https で配信できる場所（GitHub Pages など）に置いてください。ブックマークレットは開いたページのURLを元に作られるため、ローカルファイル（`file://`）のままでは使えません。
